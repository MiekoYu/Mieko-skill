# 工作汇报表达优化指南

## Five Principles

| 原则 | 要求 | 管理价值 |
|---|---|---|
| 结果先行 | 先给判断，再给依据 | 上级快速把握重点 |
| 量化锚定 | 数字带基准线、目标或变化方向 | 数字可比较才可决策 |
| 预期管理 | 偏差必须有原因和新节点 | 避免突然出现坏消息 |
| 决策辅助 | 结论要指向下一步动作 | 汇报不是只告知 |
| 客观透明 | 好坏并陈，不遮掩问题 | 建立可信度 |

## 管理判断层

默认场景：成员向直属主管汇报。优化周报、月报或其他需要决策的更新时，围绕以下六个问题组织内容：

1. 当前状态是什么：正常 / 有风险 / 已延期 / 暂缓 / 待判断。
2. 本周期形成了什么关键交付、节点或判断。
3. 判断依据是什么：数据、评审结论、协作反馈、计划节点或事实记录。
4. 当前风险或异常会影响什么：时间、质量、决策或资源。
5. 下一步做什么，预计何时形成结论。
6. 是否需要主管确认方向、协调资源或决策。

Default decision sentence:

```text
当前判断：[状态/建议]。依据是 [事实/数据/节点]；下一步 [动作]，预计 [日期] 形成 [结论/输出]；需 [确认/协调/决策]。
```

For multiple options, use:

```text
主选：A，依据是 ...
备选：B，依据是 ...
暂缓/放弃：C，原因是 ...
下一步：...，预计 ... 形成结论。
```

If evidence is insufficient, do not force a ranking:

```text
当前信息不足以判断主备排序，需补充 [验证结果/资源评估/相关记录] 后再决策。
```

## Sentence Patterns

Prefer verb-object structures:

```text
完成 + 事项 + 状态/结果
输出 + 成果物 + 用途/节点
选定 + 选项 + 原因
确认 + 范围/边界 + 依据
发布/签署/验收/关闭 + 对象 + 日期
```

Verb levels:

| Level | Meaning | Examples |
|---|---|---|
| A 产出型 | 已形成结果 | 完成、输出、签署、交付、发布、选定、确定、验收、关闭 |
| B 推进型 | 正在做但结果未明 | 推进、开展、验证、测试、调试、评估、分析 |
| C 启动型 | 刚开始 | 启动、立项、开启、探索 |

Use A-level verbs when there is a real output. If the period has mostly B/C verbs, state that the period lacks deliverable output and explain why.

## Result-Oriented Writing

Weak:

```text
本周开展协作沟通。
```

Better:

```text
完成 [数量] 项协作沟通，基于 [记录/验证结果] 确认 [当前结论]；[事项] 因 [原因] 暂缓，下一步 [动作]，预计 [日期] 形成结论。
```

Weak:

```text
对 [事项] 进行了分析。
```

Better:

```text
[事项] 评估完成：选项 A 基于 [依据] 具备推进条件；选项 B 存在 [风险]，建议优先推进选项 A，并于 [日期] 完成 [验证项]。
```

管理汇报式改写：

| Weak wording | Better wording |
|---|---|
| 已完成梳理 | 已完成问题复现与初步澄清，下一步验证 [事项]，预计 [日期] 形成结论 |
| 已输出初稿 | 初稿已完成内部评审，预计 [日期] 发布 |
| 已完成沟通 | 已确认 [输入] 于 [日期] 提供；当前建议 [继续推进/暂缓] |
| 待进一步分析 | 当前信息不足以判断，需补充 [数据/记录] 后形成结论 |
| 持续推进中 | 进度 [已完成项]/[总项]，当前 [正常/有风险]；下一节点为 [日期] 输出 [成果] |

## Data Rules

Any number should carry at least two of:

1. absolute value: current number
2. baseline: target, previous period, competitor, old design, industry value
3. direction/range: improved, declined, flat, +X, -X, X to Y

Bad:

```text
指标 X 为 [当前值] [单位]。
```

Better:

```text
指标 X 当前为 [当前值] [单位]（目标 [目标值] [单位]，较 [对比周期] [提高/下降] [变化值] [单位]），主要影响因素为 [原因]。
```

## Progress Writing

Use one of these:

```text
进度 [已完成项]/[总项]，正常。
进度 [已完成项]/[总项]（计划 [计划完成项]/[总项]），滞后约 [比例]，原因：[原因]，预计 [日期] 追平。
完成 [比例]，剩余工作为 [事项]，预计 [日期] 完成。
已完成上一阶段：[成果]；当前阶段：[状态]；下一里程碑：[成果]（预计 [日期]）。
```

For cross-period items, connect trends:

```text
[上期] 完成 [数量]/[总量]，[本期] 完成 [数量]/[总量]，较上期 [提高/下降] [变化值]；当前节奏 [正常/有风险]。
```

## Problem and Risk Writing

Use S-B-N:

| Part | Meaning | Required content |
|---|---|---|
| S Situation | happened status | objective fact |
| B Because | reason/root cause | analysis, not excuse |
| N Next | next action | owner/action/date |

Delay template:

```text
原定节点：[原日期]。
当前状态：完成 X%，剩余 Y 项。
延期原因：...
新节点：预计 [新日期]。
影响评估：影响 ...；不影响 ...
补救措施：...
需支持：...
```

Risk template:

```text
[风险事件]（概率：[高/中/低]；影响：[高/中/低]）。当前判断依据：[依据]。下一步：[动作]，预计 [日期] 形成结论。
```

面向主管的问题汇报，信息具备时包含以下六项：

```text
问题：...
影响：影响 ... 节点/决策/测试进度。
当前判断：...
已采取：...
下一步：[动作]，预计 [日期] 完成/形成结论。
需支持：...
```

## Monthly Overview

Use a three-part overview:

```text
本月核心产出：
1. ...
2. ...

需关注的偏差：
- ... -> 影响 ...；已采取/计划 ...

下月重点：
- [事项]，预计 [日期] 输出 [成果]
- ...，需 ... 支持/确认
```

## 主管关注点检查清单

面向直属主管或类似管理者时，主动覆盖：

| 关注点 | 检查项 |
|---|---|
| 结果对比 | 与什么比较？变化多少？ |
| 资源投入 | 需要哪些成本、时间或人员投入？ |
| 时间节点 | 日期是否明确，是否按计划推进？ |
| 协作边界 | 责任、输入和交付边界是否清楚？ |
| 价值影响 | 对目标、用户或业务的影响是什么？ |
| 风险判断 | 概率、影响和应对措施是否明确？ |

## Standard Output Templates

### Weekly or Monthly Report

```text
一、计划
- 本周期目标：...
- 关键节点：...

二、达成情况
- 项目状态：正常 / 有风险 / 已延期 / 待判断
- 当前进度：...
- 本周期关键完成：...

三、输出成果
- 已形成：...
- 关键判断：...

四、异常与问题
- 问题：...
- 影响：...
- 当前判断：...

五、改善对策
- 已采取：...
- 下一步：...，预计 ... 完成/形成结论

六、所需支持
- 需确认：...
- 需协调：...
- 需决策：...
```

When there is no issue or no support need, write `当前无新增异常` or `当前无需额外支持`.

### Option or Collaboration Evaluation

```text
当前建议：继续推进 / 有条件推进 / 暂缓 / 放弃。
主选：...，依据：...
备选：...，依据：...
主要风险：...
下一步：...，预计 ... 形成结论。
需决策：...
```

### Decision Request

```text
当前判断：...
方案对比：...
建议方案：...
建议依据：...
风险及应对：...
请确认：...
```

## Avoid

Avoid vague or inflated phrases, especially:

```text
已完成梳理
阶段性推进
持续跟进
进一步分析
相关工作有序开展
赋能
闭环
拉通
```

Prefer:

```text
已完成问题复现与初步澄清
已形成第一轮判断
已通过内部评审
预计 [日期] 发布
主选 [选项 A]，备选 [选项 B]
下一步验证 [事项]，预计 [日期] 形成结论
```
